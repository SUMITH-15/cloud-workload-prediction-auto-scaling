# ☁️ Cloud Workload Prediction & Auto-Scaling System

---

## 🚀 Project Overview

This project predicts future cloud workload and automatically makes scaling decisions using a hybrid deep learning model.

The system combines multiple models:

* LSTM (Long Short-Term Memory)
* GRU (Gated Recurrent Unit)
* CNN (Convolutional Neural Network)
* MLP (Multi-Layer Perceptron)

---

## 🧠 Key Features

* 📊 Predicts CPU, Memory, Jobs, and Users
* ⚡ Intelligent Auto-Scaling (Scale Up / Down / Stable)
* 🤖 Hybrid Deep Learning Model
* 📈 Accuracy Tracking
* 🖥️ Interactive GUI Dashboard using Tkinter
* 📉 Visualization with Matplotlib

---

## 🛠️ Technologies Used

* Python
* PyTorch
* Pandas & NumPy
* Scikit-learn
* Matplotlib
* Tkinter

---

## 📂 Dataset

Cloud workload dataset containing:

* CPU Utilization
* Memory Consumption
* Job Count
* Active Users

---

## ⚙️ How It Works

1. Data preprocessing and feature engineering
2. Sequence creation for time-series prediction
3. Training hybrid deep learning model
4. Predicting next-hour workload
5. Intelligent scaling decision
6. Job allocation to systems
7. Visualization through dashboard

---
